# Portfolio Website — Mohamed Bakkouri

Personal portfolio for **Mohamed Bakkouri**, Digital Marketing Specialist based in Fès, Morocco.

Built with a **Swiss + Motion** design direction: strict 12-column grid, monochrome palette with a single Swiss Red accent (`#E63946`), kinetic typography, and a playful physics-based dot easter egg in the hero.

## Stack

- **Next.js 16** (App Router, Turbopack)
- **TypeScript 5**
- **Tailwind CSS 4** + **shadcn/ui** (New York)
- **Framer Motion** for animation
- **Space Grotesk** (display), **Inter** (body), **Geist Mono** (labels)

## Sections

1. **Hero** — kinetic name reveal, cursor-driven accent dot (click to play physics mode), portrait with grayscale → color on hover
2. **About** — bio, location, status, languages (FR / AR / EN), education (ENCG Fès + ECS)
3. **Experience** — three roles with company logos and outcome metrics
4. **Skills** — six-discipline grid, qualities strip, 13-tool marquee
5. **Projects** — three case studies (Ghmoiya, Ghaiti, UrbanFlex)
6. **Certifications** — four official certs with LinkedIn verification CTA
7. **Contact** — large email CTA on dark background

## Run locally

```bash
bun install
bun run dev
```

Open `http://localhost:3000`.

## Deploy

This site is built for **Vercel**. Connect the repo at [vercel.com/new](https://vercel.com/new) — auto-detects Next.js, no custom build settings required.

## Easter egg

Click the red dot after "BAKKOURI" in the hero. Drag it around — gravity, momentum, wall bounces. Click again to send it back home.
